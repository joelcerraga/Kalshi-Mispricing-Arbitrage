The Liquidity Behind the Quote

Twenty REST observations reveal how much size is displayed at each ask. The companion graph sweeps the final recorded book, making the effect of order size visible.

Order-book liquidityResearch paper ↗

Drag to rotate · Scroll to zoom · Hover to inspect. A 2D companion supports reading the same scenario.

How to read it

Each 3D curve is a recorded observation. Price, elapsed collection time and cumulative contracts occupy the three axes. Change the contract to inspect a different book. The two-dimensional graph compares average acquisition cost with a raw-fee scenario; a missing point means insufficient displayed depth.

Interpretation and limits

The observations are from 17 October 2026, not current quotes. HTTP collection times are not exchange timestamps. Displayed liquidity does not establish a fill, queue position or an executable arbitrage. Python calculations additionally model fee rounding.
