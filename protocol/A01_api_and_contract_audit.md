# A01 — API and contract audit

Recorded 17 October 2026, before historical model fitting or test scoring.

The batch-candle endpoint rejects requests whose potential time grid exceeds 10,000 candles, even when the number of nonempty observations would be smaller. Eight-day batches are reduced from 80 to 32 tickers. Archived candles are fetched by market when the live batch endpoint is empty. The two tiers use different names for decimal-dollar price fields; both are parsed explicitly, without inferring cents from a numeric magnitude. Failed probes and successful source snapshots remain distinguishable.

The GLOBALTEMPERATURE terms state that resolution uses the source's full reported precision. Integer-labelled intervals that partition integer temperatures may leave gaps for noninteger temperatures. Therefore equal-quantity basket summaries are conditional integer-resolution diagnostics. The general payoff optimiser includes every boundary and intervening region, including all-zero YES states when they exist. The fair-value contingency remains an additional unverified payout set and blocks an unconditional arbitrage certificate. Historical probability scores are conditional on the observed event universe having exactly one binary winner; a zero-winner, scalar or disputed resolution is an exclusion, not a silently normalised outcome.

The batch order-book response contains no per-book exchange timestamp. Request round-trip time is retained as an observation-uncertainty bound, not labelled exchange latency. A fast HTTP response by itself cannot establish atomic cross-market observation. The live sample is a brief engineering pilot, not an estimate of how frequently opportunities occur over days or weeks.

The developer agreement places restrictions on data storage, redistribution and public references. The empirical cache is private working material; public data redistribution and any release of empirical outputs require a separate rights review. The final GitHub stage has not started. The open research package can be structured around original code, synthetic demonstrations and user-supplied data; free endpoint access is not evidence of an open-data licence.

The original protocol remains intact. No model is selected using held-out performance and no final paper is compiled at this stage.
